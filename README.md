# WA Chat Viewer

A single HTML file that opens a WhatsApp chat export in the browser. Messages and media stay on your computer. Nothing is uploaded.

## Open it

Open `whatsapp_Chat_Viewer_Offline.html` in a desktop browser.

1. In WhatsApp, export a chat and include the media.
2. Drop `_chat.txt` and the media files here, or choose the export folder.
3. Choose which sender is you. Those messages appear on the right.
4. Select **Tampilkan chat**.

## In the viewer

- Grouped bubbles, a color per sender, and a label for each day
- Search, with a match counter such as `2/14`
- Filter by sender
- Swap which side the bubbles sit on
- Download a standalone HTML file with the media embedded, so the chat can be opened on another device

That downloaded file can become large when the chat contains a lot of media.

The labels inside the page are in Indonesian.

## Privacy

This repository contains only the viewer. Chat exports, photos, voice notes, and contact files are not included.
